الطريقة 1 - من الشريط:
1. فوق في شريط العنوان، دوس على 🔒 أو ⓘ
2. دوس على Site settings / إعدادات الموقع
3. لاقي Location / الموقع الجغرافي
4. غيره من Block إلى Allow / سماح
5. اعمل Reload / إعادة تحميل للصفحة

الطريقة 2 - من إعدادات Chrome:
1. افتح Chrome → ثلاث نقط فوق → Settings
2. Privacy and security → Site Settings → Location
3. شيل الحظر عن موقعنا أو خلي كل المواقع Allow
4. ارجع واعمل Reload
